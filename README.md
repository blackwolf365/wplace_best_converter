# 🎨 Wplace Palette Studio

**Wplace Palette Studio** is an advanced, client-side image converter designed specifically for the **Wplace** canvas. It converts any image or pixel art into the official 63-color Wplace palette with high accuracy and customizable dithering.

### ✨ Key Features:
* 🧠 **Oklab Color Space:** Uses modern perceptual color math for natural color matching, accurate shadow merging, and contrast protection.
* ✨ **Dizzy Dithering:** Includes the modern Dizzy Dithering algorithm to eliminate directional artifacts and banding. (Also supports Floyd–Steinberg, Atkinson, and Bayer matrices).
* 🔒 **100% Local & Private:** All processing happens directly in your browser using vanilla JS and HTML5 Canvas. No image data is ever uploaded to a server.
* 🛠️ **Full Manual Control:** Group colors by target palette shade, override individual color mappings, protect tiny accent details, and pick pixels directly on the canvas.
* ⚡ **Non-Destructive Workflow:** Built-in Undo/Redo history, Nearest Neighbor resolution scaling, and high-DPI view controls.
